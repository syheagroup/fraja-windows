# Fraja pour Windows

Installeurs de **Fraja**, lecteur IPTV (playlists M3U et comptes Xtream Codes) pour Windows 10 et 11 (64 bits).

**Téléchargement et instructions : [fraja.app/windows](https://fraja.app/windows)**

Ce dépôt ne contient que les versions publiées (onglet *Releases*). Fraja est un lecteur : il ne fournit aucun contenu,
chaîne, playlist ou abonnement.
